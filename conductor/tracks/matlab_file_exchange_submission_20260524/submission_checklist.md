# MATLAB File Exchange Submission Checklist

This checklist captures the external steps required to finish `mchs-matlab-interop@0.1.0`.

## Inputs

- Package: `mchs-matlab-interop`
- Version: `0.1.0`
- Local surface: `bindings/matlab/`
- Prepared artifact: `bindings/matlab/mchs-matlab-interop-0.1.0.zip`
- Submission metadata: `bindings/matlab/file-exchange-submission.json`

## Required steps

1. Sign in to MathWorks File Exchange with the publishing account.
2. Create a new File Exchange submission named `mchs-matlab-interop`.
3. Upload `bindings/matlab/mchs-matlab-interop-0.1.0.zip`.
4. Copy the description, license, tags, version, and repository details from `bindings/matlab/file-exchange-submission.json`.
5. Submit the package for File Exchange review.
6. Record the submission URL, review state, or confirmation email in the track evidence.
7. Verify the public File Exchange page exposes version `0.1.0`.

## Evidence to record

- Submission URL or review email
- Publisher account used for the upload
- Archive checksum
- Review status or reviewer notes
- Public File Exchange page URL for version `0.1.0`

## Completion rule

Do not mark the track complete until File Exchange has accepted or published the package and the public page shows version `0.1.0`.
