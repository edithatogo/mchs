# Specification: docs sota starlight completion

## Overview

This track operationalises the Starlight/Astro documentation requirements in
`conductor/requirements.md` and the architecture in `conductor/design.md`. It
exists to make the public documentation comprehensive, versioned,
support-status aware, tutorial-rich, and aligned with repository governance
contracts.

## Requirements

- Publish Starlight pages for current docs, versioned docs, calculator coverage,
  source archive status, public calculator contract, Starlight extensions, and
  governance navigation.
- Mirror the current and 2026 docs paths without letting navigation claims
  exceed support-status evidence.
- Publish the public calculator contract schema as a machine-readable docs-site
  artifact.
- Keep source archive gaps explicit.
- Require implementation evidence, validation evidence, documentation, and
  review evidence before completion.

## Acceptance Criteria

- Docs-site homepage positions the current public contract and delivery
  surfaces.
- Calculator coverage, versioning, Starlight extensions, public contract,
  contract schema, source archive, and governance index pages are present.
- Source archive gaps are explicit.
- Required validation, docs, review, and publication evidence are present or
  explicitly gap-recorded.
- No scaffold, stub, TODO, fake, or mock-only artifact is treated as completion
  evidence.
