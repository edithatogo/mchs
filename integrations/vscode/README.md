# MCHS Tools

VS Code helper extension scaffold for MCHS contract, MCP, and CLI workflows.

## Commands

- `MCHS: Show Registry Status` displays the repository contract surface that governs language and registry publication status.

## Publication status

The extension is published as `edithatogo.mchs-tools` on Open VSX and Visual Studio Marketplace. Version `0.1.1` refreshes this README so the packaged extension no longer describes already-completed publisher setup as a remaining user-facing blocker.

## Local packaging

Run `npm install` in this directory, then `npm run package` to produce the `.vsix` artifact for authenticated Open VSX or Visual Studio Marketplace publishing.
