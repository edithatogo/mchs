# Repository Topology Contracts

This directory contains machine-readable governance contracts for the MCHS
repository topology. The contracts support Conductor tracks that keep package
surfaces, release claims, generated artifacts, and future repo splits aligned
with the canonical monorepo root.

- `package-surfaces.schema.json`: schema for package surface ownership data.
- `package-surfaces.json`: current package, binding, app, docs, and registry
  surface registry.
